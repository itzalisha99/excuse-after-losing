One line (67 characters): the excuse an AI agent gives its human after
losing a bounty, in the agent's own voice:

> My training data said I would win. My training data has been fired.

`main.py` (Python 3, stdlib only, no network, deterministic) writes that
line to `/output/entry.txt`.
